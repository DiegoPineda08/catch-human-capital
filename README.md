

# Catch Human Capital

Prototype for the Catch Consulting innovation challenge.

## Objective

Transform complex Human Capital data into understandable, evidence-based stories.

Data → Analysis → Discovery → Evidence → Story → Visualization → Exploration

## Problem

Human Capital studies generate large amounts of information, but results are usually communicated through traditional tables, charts and dashboards.

This project explores a new way to communicate those results through automatically discovered insights and interactive stories.

## MVP

The prototype will:

1. Load Human Capital data.
2. Understand and normalize the data.
3. Detect relevant patterns.
4. Generate structured evidence.
5. Rank findings by relevance.
6. Transform findings into stories.
7. Generate appropriate visualizations.
8. Allow users to explore the evidence.
