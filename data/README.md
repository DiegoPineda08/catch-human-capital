# Carpeta data/

Aquí van los archivos REALES con los que quieres trabajar (Excel, CSV, PDF, .md o .txt), por
ejemplo `BASE_HISTORICA_LIMPIA.xlsx`. Cópialos a mano en tu computadora.

- Al iniciar, DINAMO carga TODOS los archivos de esta carpeta. Si está vacía, carga los de `ejemplos/`.
- Esta carpeta está en `.gitignore`: nada de aquí (salvo este README) se sube a GitHub,
  porque los datos del concurso son confidenciales.
